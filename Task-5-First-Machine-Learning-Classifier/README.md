# Task 5 - First Machine Learning Classifier

## Internship Project

This project demonstrates a complete machine learning classification workflow using the Titanic dataset and Scikit-Learn.

## Objective

The objective of this task is to build and evaluate a machine learning classification model using a train-test split and standard evaluation metrics.

## Dataset

The Titanic dataset is used for this classification task.

### Target Variable

`survived`

- 0 = Did not survive
- 1 = Survived

## Features Used

- Pclass
- Sex
- Age
- SibSp
- Parch
- Fare
- Embarked

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Google Colab

## Machine Learning Algorithm

### Decision Tree Classifier

The Decision Tree Classifier is used to perform the classification task.

## Workflow

1. Dataset loading
2. Data exploration
3. Missing value handling
4. Feature selection
5. Categorical data encoding
6. Train-test split
7. Model training
8. Prediction
9. Model evaluation
10. Confusion matrix analysis
11. Feature importance analysis

## Evaluation Metrics

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Conclusion

The Decision Tree Classifier is trained on the Titanic dataset and evaluated on unseen test data using multiple classification metrics and a confusion matrix.
