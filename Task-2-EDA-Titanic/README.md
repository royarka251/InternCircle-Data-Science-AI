# Task 2 - Exploratory Data Analysis on Titanic

## InternCircle Virtual Internship - Data Science & AI

This task focuses on performing Exploratory Data Analysis (EDA) on the classic Titanic dataset using Python and Pandas.

## Objectives

- Load and inspect the Titanic dataset
- Perform basic data exploration
- Identify missing values
- Check and handle duplicate records
- Perform grouping and aggregation
- Extract meaningful insights from the dataset

## Tools Used

- Python
- Google Colab
- Pandas
- NumPy

## Dataset

Titanic dataset provided through the Seaborn library.

## Expected Outcome

A complete exploratory data analysis of the Titanic dataset using Pandas.
