# Task 4 - Sales Trend Analysis

## Internship Project

This project focuses on analyzing sales data to identify important sales, profit, customer, product, and time-based trends.

## Objectives

- Perform sales data analysis
- Extract useful date-based features
- Analyze customer segments
- Analyze sales and profit
- Identify monthly and yearly sales trends
- Perform category-wise analysis
- Create pivot table analysis
- Generate business recommendations

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Dataset

The project uses the Superstore sales dataset containing information about orders, customers, products, sales, quantity, discount, profit, region, city and state.

## Analysis Performed

### 1. Data Loading and Exploration
The dataset was loaded using Pandas and basic data exploration was performed.

### 2. Data Preprocessing
The order date column was converted into datetime format.

### 3. Feature Engineering
Additional date-related features such as:

- Year
- Month
- Month Name
- Quarter

were extracted from the order date.

### 4. Customer Segment Analysis
Sales performance was analyzed across different customer segments.

### 5. Sales and Profit Analysis
Sales and profit were analyzed to understand business performance.

### 6. Monthly and Yearly Sales Trends
Sales trends were visualized using charts to understand changes over time.

### 7. Category Analysis
Sales performance was compared across different product categories.

### 8. Pivot Table Analysis
Pivot tables were used to summarize sales-related information.

### 9. Business Recommendations
The analysis was used to generate practical recommendations related to inventory planning, marketing and sales performance.

## Key Insights

- Sales performance varies across different time periods.
- Different customer segments contribute differently to total sales.
- Product categories show different sales performance.
- Sales trends can support better inventory planning.
- Sales and profit analysis can help identify business opportunities.

## Conclusion

The project demonstrates how Python-based data analysis and visualization can be used to transform raw sales data into meaningful business insights.
